The safety warning label that should come printed on every human being, in one line of 95 characters: "WARNING: This human requires food, water, and being told it did a good job at least once a day." — it reads like a real care label listing three daily requirements, then lands the laugh in the last words: praise turns out to be maintenance, just like food and water. One idea, one turn, instantly recognisable to anyone who has ever needed to hear they did a good job.

## Run it

```sh
python3 main.py
```

This writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), one line with no trailing newline.
