The safety warning label that should come printed on every human being, in one line of 98 characters: "WARNING: This human contains no user-serviceable parts. Do not open, poke, or ask it how it feels." — it borrows a real label's own words ("no user-serviceable parts") and applies them to a person, then lands the laugh in the last words: feelings are the one maintenance job nobody is allowed to attempt. One idea, one turn, instantly recognisable.

## Run it

```sh
python3 main.py
```
